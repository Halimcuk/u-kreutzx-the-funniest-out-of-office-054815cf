A one-line out-of-office auto-reply for the make.fun competition "The Funniest Out-of-Office". The joke turns on an inbox that answers its own auto-reply, so the sender and the inbox end up on holiday together.

> I'm out of office until Tuesday — my inbox replied to itself this morning, and now the two of them are on holiday together.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=output node main.ts
```

The entry line is 123 characters long, and the output is deterministic: every run writes the exact same text to `output/entry.txt`.
